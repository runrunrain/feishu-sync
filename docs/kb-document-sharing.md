# 标准库文档导出与内网网页分享

入口：**标准库 → 共享 → 文档导出与内网分享**。只有已发布到正式标准库的文档可以导出和分享。

## 导出 Markdown

勾选需要的文档，可按标题或路径搜索，也可全选。

- **导出单篇 .md**：选中一篇后下载 UTF-8 Markdown 正文，去除应用内部的构建文件头，保留原文链接。
- **导出 Markdown 包**：将选中文档及可取得的引用图片下载为 ZIP。文档位于 `docs/`，保留原目录层级与相对链接。解压后用 Markdown 阅读器打开；若要跳转其他文档，需要同时选中链接目标。

单篇 `.md` 不包含独立图片文件。离线看图请使用 Markdown 包。原始库、来源快照和检索索引不会随此包导出；完整迁移仍使用下方的「导出标准库」功能。

## 创建网页分享

1. 勾选允许访问的文档，选择其中一篇作为**分享基准文档**。
2. 点击**创建内网分享**，将下方生成的链接复制给内网用户。
3. 接收者在浏览器中打开链接，即可阅读基准文档。正文中的相对链接可跳转到同一分享内的文档和标题锚点；顶部始终提供**返回基准文档**和**分享目录**。
4. 不再分享时，点击对应条目的**停止分享**。该链接立即失效。

分享保存创建时的静态页面与图片。后续构建、导入或删除旧发布版本不会改变已经生成的分享；需要更新内容时应创建新分享。退出应用期间网页不可用，重新启动应用后恢复尚未停止的分享。地址由本机当前内网 IPv4 地址生成，网络变化后请重新复制链接。

网页服务使用独立 TCP **47393** 端口，与本机 MCP 的 47392 端口分开。保持应用运行，并允许本机防火墙的内网入站访问；端口冲突时先关闭占用它的程序，再重试。没有内网 IPv4 地址时只显示本机回环地址。服务启动失败时，共享列表提供「重新启动分享服务」。

## 分享范围与边界

- 网页只提供已选文档和正文引用的可用图片，没有桌面管理 API，也不开放文件目录浏览。
- 持有链接且能连接该机器的内网用户均可阅读，无需安装应用。使用明文 HTTP，只用于可信内网，不应配置公网端口转发。
- 未选中的本地文档链接显示为不可用，不会自动扩大分享范围。外部网页链接仍可打开，但远程图片不会自动加载。
- 图片从固定发布版本读取；组织化标准库还可读取与文档来源匹配、哈希校验通过的图片证据。缺失图片显示占位文字，源引用动态加载功能不在静态分享中执行。
- 同时最多保留 100 个分享；单次最多 1000 篇、32 MB Markdown 正文和 128 MB 本地图片，单图最多 16 MB。

## 开发验证

`npm run server:dev`、服务构建和 `npm test --prefix server` 会先生成 `server/dist/share-render.cjs`。它由现有 `MarkdownView` 打包而来，无需浏览器端脚本或 CDN。修改渲染器后需重新生成该文件。共享快照保存在 Agent 数据目录下的 `web-shares/`，每个随机链接单独保存页面、图片与元数据。

针对性测试：`npm test --prefix server -- --run tests/kb-distribution.test.ts`，以及 `npm test -- --run src/components/kb/KbDocumentSharePanel.test.tsx`。
