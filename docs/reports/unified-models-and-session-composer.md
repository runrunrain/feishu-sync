# 统一模型调用、空配置与会话输入框验收

2026-10-27，feat/agent-knowledge-workbench，0.3.47开发版。保留已有工作；不合并main、不推送或发版。

## 原始文档整理与干净配置

- Agent、标准库构建和原始文档整理共用model-selection的提供商、预设、协议及参数解析。整理沿用现有DirectChannel/ContentAdapter/同步失败兜底链，通过OpenAI SDK调用Chat Completions与Responses、Anthropic SDK调用Messages，兼容Electron现有Node运行时。应用模型模式下同步入口传入同一Agent选择；每个同步批次固定配置，避免中途变更目标。
- 三协议支持流式与非流式文本、输出上限、思考参数、token用量、长度截断、超时与错误；流未完整结束视为失败，错误信息遮蔽密钥。SDK重试由宿主控制，不静默切换协议。设置页提供「同步时整理原始文档」显式开关。
- 新应用配置的提供商、模型和凭据均为空。显式空providers清除旧兼容字段，不回退旧密钥、端点或模型；允许删除最后一个提供商、最后一个预设，保存与重载后不自动补回。旧的有效配置仍可迁移读取，兼容字段与选中预设一致。

## 会话模型与思考强度

- 输入框底部模型菜单可从已配置应用预设选择，也可主动读取本地Pi模型；思考面板提供关闭/最低/低/中/高五档及恢复默认。未声明思考能力的应用预设禁用强度选择。
- Agent会话元数据新增可空model_config_json列（建表DDL与幂等迁移同步）；只保存来源、提供商/预设ID或Pi模型标识、思考强度，不保存密钥或端点。接口严格验证选择，拒绝未配置、停用、无认证、未知强度和不支持思考的预设。
- 设置仅当前会话生效。会话状态返回偏好；独立就绪检查按该会话有效模型计算，不能用全局模型就绪掩盖失效的会话选择。API拒绝运行/收尾期间切换；下一次发送以选中配置重建进程并恢复历史。原有插话、队列、能力围栏与Work目录保护不变。
- 模型列表按需读取，认证探测沿用后端缓存，调整强度不触发重复认证探测。异步加载在切换会话/来源后丢弃旧响应。
- 窄窗口优先显示正文与输入框，通过顶部下拉切换/新建会话；右侧模式面板改为可关闭浮层，桌面宽屏保持分栏。
