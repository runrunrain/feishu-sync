# 页面按钮与间距优化验收

2026-10-27，开发分支 `feat/agent-knowledge-workbench`，版本保持 0.3.47。

## 调整结果

- 公共按钮统一为 32 / 36 / 44px 最小高度，收紧横向内边距，防止图标和按钮被压缩、文字竖排。输入框与选择框采用一致的行高与高度，修复自定义 className 未生效的问题。
- 卡片内边距统一为 16px，标题区纵向内边距为 12px；缩短空状态的上下留白。
- 设置分类在窄窗口自动换行，子导航移动到正文上方。只有一个子项的分组省略重复侧栏，移除重复的面包屑标题。
- 同步根目录列表在中小窗口置于编辑表单上方；Workspace 添加表单改为响应式分列；归档标题与描述分行，避免挤压。
- 插件配置导航改为可换行或分列，消除横向隐藏的配置入口；状态徽标不再被压缩成竖排。
- 总览、同步页面降低窄窗口的固定最小高度，减少空状态对后续操作区的挤占。
- 标准库工具按钮收紧为 44px，差异与版本弹窗按内容决定高度，长内容限制最大高度并滚动。构建标识可截断，来源卡片的查看提示保持可见。
- 对话未配置提示在窄窗口分行显示说明和操作，连接状态使用短标签，避免标题与操作互相挤压。
- 弹窗增加可滚动的高度上限，抽屉标题与页脚间距统一。

标准库正文的字号、行距、阅读偏好与默认收起侧栏的行为保留。
