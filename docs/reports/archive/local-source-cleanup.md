# 本地删源残留修复与指定源清理验收

日期：2026-10-27。分支`feat/agent-knowledge-workbench`，版本0.3.47；未合并main、未发版。本轮开始于4f99b4d的干净工作区。

## 原因与处理

旧清理只在全量重建时触发，只检查非空local_rel_path，且没有完整处理表格子索引与目录映射；源选择又会重新加入历史manifest引用，导致磁盘删除后仍显示旧来源。

读取原始库树、标准库源集合、Agent原始库查询及归档列表时校正本地索引；重建和快照生成也复用同一清理方法。当前源选择只列仍存在且安全可读的本地文件，历史引用保留在待更新差异/版本入口。文件缺失带来的标准库内容变化仍通过按变更更新发布，旧版本不改写。

索引校正兼容仅有绝对路径的旧行，显式清理表格关联及历史孤立子索引、不存在的目录映射，事务提交；根目录不可用、权限错误、符号链接越界、外库记录不当成删除证据。保留未成功落盘的云端待同步身份、云端修复队列与回收站。子目录扫描不会按错误的相对根清除其他目录记录。

源列表新增逐篇/层级清理入口及独立批量清理模式。清单确认后，仅将指定正文及已登记CSV移至原始库`.trash-bin/sources-*/files/`，保存cleanup.json恢复依据，然后事务删除文档/表格索引并更新索引快照。全量校验库根、文档标识、路径、构建状态与共享文件映射。移动或DB失败会回滚已移动文件；未选择的共享源不得误伤。正文可移回后重建索引，表格映射可重新同步恢复，回收单保留原映射。

## 使用边界

校正发生于读取/刷新相关视图或索引操作，不是常驻文件监视器；已打开且未刷新的源面板可点击刷新。工具内清理只处理当前本地副本；云端仍存在的节点可在之后检测中重新成为待同步项，由用户选择是否下载。历史版本为追溯证据保留，不属于残留索引。
