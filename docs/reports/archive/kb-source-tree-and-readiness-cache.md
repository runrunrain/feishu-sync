# 源树批量选择与Pi检测优化验收

日期：2026-10-27。开发分支 `feat/agent-knowledge-workbench`，应用版本仍为0.3.47；本次未合并main或发版。

## 实现

- 源选择优先采用飞书wiki父链，未同步的上级保留为层级节点；缺少父链时按本地目录分组。勾选层级同时处理本身及全部下级，父复选框显示全选/半选/未选。
- 提供全选、取消全选、反选、展开全部与收起全部；搜索批量操作覆盖匹配文档及匹配层级下级，祖先仅保留作导航。层级复选框始终作用于完整子树。列表采用虚拟行，选择不限于当前渲染行或旧50条分页。
- 批量HTTP请求通过SQLite事务保存；全量校验文档标识和库根目录，构建进行中拒绝修改，失败不部分保存。标记不修改原始正文。
- 前端跨页面共享就绪状态及一个轮询器，正常结果五分钟复用；后端按运行时/模型配置及通用Pi模型、认证文件签名缓存，正常结果五分钟、失败结果30秒，相同在途检查合并。配置更新不丢失，手动重检绕过已完成缓存。
- Pi RPC启动后立即发送get_state握手，移除正常启动先静默等待8秒的路径；保留原有超时兜底及RPC命令白名单。
