# 在可信内网共享标准知识库

本机 stdio MCP 和内网 MCP 使用相同的 17 个只读工具，查询相同的已发布标准库及已同步原始库。原始库通过 `raw_list` 浏览目录路径、`raw_search` 检索、`raw_read` 阅读，包含未参与标准库构建的源文档及已登记 CSV 附件，不需要先发布标准库。不提供 Workspace 写入、应用命令或会话操作。

Excel 原件和只读重建的工作簿可用 `raw_list_sheets` 列工作表、`raw_search_sheet` 检索单元格、`raw_read_sheet` 按工作表和行列范围读取。结果包含单元格坐标、格式化文本以及存在时的公式、超链接和合并关系；公式使用文件中的缓存值，不会重新计算。未取得或未纳管 Excel 的旧文档仍可通过 `raw_read` 阅读现有 Markdown/CSV。图表、透视表和形状不是单元格，不能保证由单元格查询还原。

`raw_search_images` 检索文档引用和工作簿内嵌图片的文件名、工作表、替代文字和已有识图缓存；按 `nextOffset` 翻完当前批后，用 `nextSourceOffset` 扫描下一批源文档。未识图的图片无法按视觉内容检索。`raw_list_images` 同时列出指定文档引用的本地图片与其工作簿内嵌图片，`raw_read_image` 返回图片内容及已有缓存描述。不会自动调用模型；图片原图超过 4 MiB 时可用 `includeImage=false` 读取不超过 20 MiB 图片的已有描述，支持 PNG、JPEG、GIF 和 WebP，其他格式会说明不可用。

`raw_links` 读取应用同步建立的引用索引，支持出链、入链、标题和已同步状态；新版本应用需启动一次以生成包含引用的原始库清单，旧清单会明确返回 `raw_references_unavailable`，不会误报零引用。资料或清单变化导致翻页失效时按提示从第一页重新读取。

本机 MCP 在桌面应用关闭后仍可使用；内网 MCP 由应用管理独立子进程，应用退出或停用共享后停止监听。应用启动时及运行期间约每 10 秒更新同一份原始库清单，沿用应用的成功本地版本与删除过滤规则。应用关闭后，本机 MCP 使用最后的清单读取本地文件；返回的 `catalogUpdatedAt` 表示清单更新时间，不代表云端实时状态。不存在、越界、回收站中的文件不提供读取。

已有本机安装在升级并启动应用后，可自动识别同一应用的原始库清单；自定义配置可于「本机 MCP 安装」点击更新并重启客户端，显式加入清单参数。内网网关启动时使用同一清单。接收设备不需要复制源文件或安装本应用。分页时把 `nextOffset` 作为下一次 `offset`，阅读携带 `contentHash`、列表与检索携带 `catalogHash`，变化时会提示重新查询。

## 开启与连接

1. 先构建并发布标准库；未发布时可以连接，但查询会返回 `kb_not_published`。
2. 打开 **设置 → Agent 标准库 → 知识库共享**。共享默认关闭，开启前需确认明文传输风险。
3. 在高级设置选择一个网卡 IP，必要时修改固定端口（默认 47391）。`auto` 自动选一个私网 IPv4；建议为常用设备锁定 IP，并在路由器做 DHCP 保留。
4. 开启并等待状态变为运行中。复制页面给出的 URL 和令牌，在客户端设备配置。macOS 还可能显示系统 `.local` 地址，能否解析取决于所在网络。
5. 客户端先调用 `list_knowledge` 或 `get_release_info`，再检索、精读。工具和版本引用用法见 [Agent 与 MCP 使用说明](agent-knowledge.md#给其他工具连接只读-mcp)。

HTTP 传输**未加密**。令牌和正文可能被同网段嗅探；只在家庭、公司有线网或可信 Wi-Fi 使用，不在公共、访客网络开启。需要加密时优先绑定 Tailscale/WireGuard 地址。`0.0.0.0` / `::` 会监听所有网卡，必须额外确认，包括 VPN、热点、虚拟机网桥；源地址私网限制仍生效。

本应用不添加防火墙规则，不广播 MCP 服务，不做端口转发，也不支持公网共享。

## 客户端配置

令牌使用环境变量，避免写入项目仓库或命令历史。页面的「复制客户端配置」生成的是环境变量引用，不含明文令牌。将片段合并进客户端自己的配置文件，不覆盖已有其他服务器。

### pi

```json
{
  "mcpServers": {
    "feishu-kb": {
      "url": "http://主机IP:47391/mcp",
      "headers": { "Authorization": "Bearer ${FEISHU_KB_TOKEN}" },
      "description": "飞书同步标准知识库（只读）：策划与程序设计文档的检索、grep、章节大纲与正文读取",
      "timeout": 60
    }
  }
}
```

在启动客户端的环境中设置 `FEISHU_KB_TOKEN`。pi 也支持 `pi mcp add feishu-kb --url <URL> --bearer-token-env-var FEISHU_KB_TOKEN`；具体配置文件位置和参数以所装客户端版本为准。

### Claude Code

项目 `.mcp.json` 示例：

```json
{
  "mcpServers": {
    "feishu-kb": {
      "type": "http",
      "url": "http://主机IP:47391/mcp",
      "headers": { "Authorization": "Bearer ${FEISHU_KB_TOKEN}" }
    }
  }
}
```

不要直接把包含 `$FEISHU_KB_TOKEN` 的 `--header` 命令粘进 shell：shell 会先展开变量，客户端可能将明文写进配置。文件中的 `${FEISHU_KB_TOKEN}` 应由客户端运行时展开。客户端对环境变量、输出截断和断线恢复的支持随版本变化；本次实际测量和未覆盖项以交付验收记录为准。

## 令牌与访问记录

- 页面默认只显示掩码；点击显示或复制才读取明文，每次读取都会留下审计。
- **停用**立即停止监听，默认保留令牌；重新启用后原设备无需重配。可选择停用并作废令牌。
- **轮换**会停止旧进程、作废旧令牌和全部会话；所有设备需更新环境变量并重新连接，没有旧令牌宽限期。
- desktop、CLI 和内网令牌互不接受；内网令牌不能管理应用或执行命令。
- 最近访问只记录来源、工具、版本、状态、耗时等元数据，不记录查询正文、请求体或令牌。完整审计在数据根的 `agent/audit/kb-lan-mcp.jsonl`，达到约 5MiB 后保留一份 `.1`。
- 令牌保存在本机数据根独立 secrets 文件中，不在普通 config.json 内。它不是操作系统沙箱：同账号运行的可信程序仍可能读取本机数据。

## 常见问题

| 现象 | 排查 |
|---|---|
| 开启后端口占用 | 修改端口并更新客户端 URL；应用不会静默换端口 |
| 绑定地址不可用 / 无私网网卡 | 确认网卡连接；IP 恢复后会自动尝试恢复。auto 换址会改变 URL |
| 产物缺失 | 开发态先构建 server；桌面安装包应自带网关 CJS 产物 |
| 连接被拒绝 / 超时 | 确认共享运行中、IP/端口正确；客户端可执行 `nc -vz <IP> <端口>`；检查同网段、访客 Wi-Fi 客户端隔离和防火墙 |
| macOS 防火墙弹窗 | 只在可信网络允许应用传入连接；阻止所有传入连接时不可用。开发态显示 node/Electron，升级签名变化可能再次询问 |
| Windows 防火墙弹窗 | 仅允许「专用网络」；应用不自动修改规则 |
| HTTP 401 | 缺失、错误或已轮换的 Bearer；重新复制最新令牌。不需要 OAuth 登录 |
| HTTP 403 | 来源不在允许网段，或请求带 Origin（浏览器直连被拒绝）；不要通过公网代理或转发头绕过 |
| HTTP 429 | 同源认证失败过多，暂停并核对令牌，封禁持续约5分钟 |
| HTTP 404 会话不存在 | 网关重启、IP变化或会话过期；客户端重新 initialize/重连 |
| HTTP 503 / `kb_sessions_full` | 会话已满，关闭不用的客户端或调整最大会话数 |
| 工具返回 `kb_busy` | 排队已满或等待过久；按 retryAfterMs 重试，减少并发 |
| 旧版本不可用 | 发布保留策略已清理旧 release；重新获取当前版本和行号 |
| 中文正文中段不见了 | 客户端可能按 UTF-8 字节截断；产品已对 pi 会话限制为最多6000字符页，请按next继续。其他客户端可降低 KB_MCP_MAX_CHARS 或按章节/行分页，不能把客户端截断误当正文缺失 |

最大会话默认16，可设1–64。全局在途4、每会话2，排队最多32且最长10秒；这些限制由进程统一管理，不占用 Agent 进程池。正则是受限 JS RegExp，极端回溯可能触发看门狗杀掉并重启独立网关；这会断开所有共享会话，但不应阻塞桌面主进程。
